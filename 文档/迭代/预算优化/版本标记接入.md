# ERP-I003 版本标记接入

日期：2026-10-27。用于研发、测试和业务评审快速识别本次迭代范围。公共组件维护在 [原型/公共](../../../原型/公共/版本标记.md)，预算只维护配置，不依赖 ERP 外 Revenue 文件。

## 需求与操作流程

1. 打开 [ERP 统一工作台](../../../index.html)，顶栏下方只有一条公共“版本标记”工具栏，统一管理页面和菜单。独立演示可打开[当前导出](../../../原型/预算管理/预算优化/预算管理交互原型_当前.html)，保留预算本地入口；旧的无后缀 HTML 继续作为迁入基线保留。
2. 选择 `ERP-I003 · 预算优化`，点击“显示标记”。颜色分别为新增、优化、规则，虚线框标出变化区域，编号与清单一一对应。编号贴近原区域，仅遮字或相撞时稍作偏移；悬停或聚焦编号加粗对应框，点击查看说明。
3. 点击区域编号打开右侧说明；“全部变更”可查看整个迭代，或切换为当前页面。说明包含变化内容、当前原型覆盖程度及需求／测试入口。
4. 点击“定位此处／前往页面”使用原有页签导航；月度、全年相关项会自动切换对应视图。纯规则没有区域定位按钮。
5. 点击“隐藏标记”恢复普通查看；开关和版本在当前浏览器保存。刷新不改变标记偏好，业务数据仍遵循原型原有保存规则。

本页项数包括条件视图与纯规则，可见处数只统计视口内实际展示的区域，两者不必相等。标记辅助评审，不代表生产功能已经验收。

## 可视化维护（2026-10-27）

入口位于工作台顶部“版本标记”工具栏右侧的 **配置标记**。页面与菜单共用显示开关、版本筛选、变更清单、配置面板及导入导出。面板左侧搜索及选择标记，右侧维护标记范围（页面区域／菜单区域）、所属模块、迭代、类型、标题、页面、变更说明、交付说明和关联资料；顶部展开“管理迭代”新增或改名。工作台默认 16 项（正文 13 项＋菜单 3 项），统一编号；预算独立页面保留本地工具栏及正文 13 项。

新增流程：先进入目标业务页面 → 配置标记 → 新增标记 → 选择页面／菜单范围并填写内容 → 选择页面区域 → 点击并调整范围 → 使用此区域 → 保存标记。页面范围在业务内容中选区，菜单范围在公共一级／二级菜单选区，均返回同一配置面板。点选区域不执行业务按钮，Esc 取消；纯规则可跳过选区。保存立即生效，刷新保留；删除标记、导入和恢复默认均需确认，未保存修改关闭或切换条目时提示。

配置保存于当前浏览器，不自动写回 ERP 文件。工作台导出 JSON 同时包含菜单和页面，接收方在统一入口导入；项目共享时导出配置脚本，更新 `原型/公共/version-marks-config.js`（全局名 `ERPVersionMarks`）。预算独立页仍使用 `prototype/iteration-marks.js`（全局名 `BudgetIterationMarks`），独立页内容更新后运行 `node build.cjs` 生成 `_当前.html`。同步迭代资料及台账，禁止覆盖无后缀迁入基线。已有本地配置优先，需要查看新源码配置时点击“恢复项目配置”。

首次打开统一入口时，自动合并旧页面与菜单的自定义配置及迭代，不删除旧数据。统一保存键为 `erp-iteration-marks:erp-version-marks:config`；开关和版本使用同键去掉 `:config`。统一配置存在后不重复迁入；没有旧自定义内容时不固化项目默认配置。

导入先校验模块编号、迭代关系、唯一标记编号及字段；失败保持原配置。浏览器禁止存储时提示仅本次预览有效，仍可导出。公共组件可被其他迭代接入复用，回单未被自动注入。

本轮新增编辑器浏览器验证已通过：新增／编辑／删除、迭代关联保护、点选拦截、Esc 取消、刷新回读、JSON 导入校验与完整回读、导出脚本执行后配置一致、恢复默认、存储不可用提示及工作台配置入口。79 项单元测试、原标记浏览器回归与工作台 10 组场景通过；1440×1000 与 1024×768 面板截图已检查。

## 编号避让与公共菜单（2026-10-27）

按用户最新反馈，撤去独立编号栏，恢复贴近原区域的编号。沿用原来的边缘位置，仅小区域遮字或编号相撞时，向附近空白处作最小偏移；小区域使用紧凑编号。显示标记不会改变页面或侧栏宽度，目标虚线框和悬停加粗关联保留。定位避开可见文字、输入控件及已放置编号，极密集无空白的位置不强行叠放，说明仍保留在“全部变更”。

菜单标记属于统一版本标记的“菜单区域”范围，默认三项：办公管理、申请、审批。进入同一“配置标记”面板后新增或选择标记 → 范围选菜单区域 → 选择页面区域 → 点击一级／二级菜单 → 使用此区域 → 保存。选区期间不执行业务导航，普通模式仍按原菜单交互。折叠一级菜单隐藏子项编号，展开恢复；导航整体隐藏时编号消失。

`原型/公共/menu-marks.js` 仅提供菜单默认片段，由 `version-marks-config.js` 与预算正文聚合为一个配置集。工作台同一开关同时控制菜单及当前业务页面，同一版本筛选同时过滤两类内容，“全部变更”默认 16 项，“当前页面”包含当前模块页面及公共菜单。预算嵌入时隐藏重复工具栏，独立预算 HTML 继续展示正文标记。回单业务页未注入组件，切到回单时公共入口保留。

本轮验证：1024／1440 宽度下检查原位编号与可见文字的矩形无交集、编号互不重叠；开启前后业务区位置／尺寸及菜单侧栏宽度一致，无独立标记栏；12 个重复目标叠加嵌套目标仍可独立点击。一级菜单点选不展开、二级说明、刷新、菜单折叠及导航隐藏恢复通过。原标记及编辑器浏览器回归、79 项单元测试、工作台 10 组场景与当前独立构建回归同步执行。截图：[1440](版本标记验收/页面与菜单标记_1440.png)、[1024](版本标记验收/页面与菜单标记_1024.png)。

## 文件与维护

| 文件 | 责任 |
|---|---|
| `原型/公共/iteration-marks.js` | 通用显示、筛选、说明、定位、可视化配置、区域点选、导入导出与本地存储 |
| `原型/公共/version-marks-config.js` | 工作台统一配置，默认聚合页面及菜单；统一导出脚本更新此文件 |
| `原型/公共/iteration-marks-bridge.js` | 根工作台唯一入口与业务 iframe 渲染器同步、区域点选回传及旧配置合并；独立协议校验消息来源 |
| `原型/公共/menu-marks.js` | 菜单默认片段，统一配置聚合来源 |
| `原型/预算管理/预算优化/prototype/iteration-marks.js` | 本轮 13 项内容与资料关联 |
| 本模块 `index.html / app.js` | 加载组件，提供页面标识及既有导航适配 |
| 本模块 `build.cjs` | 内联公共组件，输出 `_当前.html`；拒绝覆盖迁入基线，详情源码只读内联 |

后续预算迭代在配置中追加版本及标记；其他模块按公共接入文档新增自己的配置。无需复制组件或改动回单业务代码。公共菜单、页签协议和预算业务计算规则未因标记功能调整。

工作台页面标记需登记模块并接入桥接渲染器；独立页沿用组件本地入口。根端仅接受登记 iframe 消息，业务渲染器仅接受父窗口消息，避免与公共页签协议混用。
