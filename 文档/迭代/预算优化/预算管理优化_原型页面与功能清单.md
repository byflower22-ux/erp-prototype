# 预算管理优化：原型页面与功能清单

版本：V1.0｜整理日期：2026-10-20｜用途：作为低保真原型及需求评审依据

2026-10-23 补充：预算原型已接入 ERP 公共菜单、顶部栏与工作页签。当前入口及新增导航／状态保留／关闭流程以[公共框架接入](公共框架接入.md)为准；以下业务规则继续沿用已确认版本。

## 1. 已确认的设计范围

1. 沿用现有预算编制与管控配置；管控方式包括一级预算月累计、一级预算月不累计、二级预算月累计、二级预算月不累计。
2. 月累计指财年起始月至预算归属月累计，前期结余可使用，未来月份预算不可提前使用。财年月份沿用系统配置。
3. 报销、付款申请已有按管控规则计算余额的能力；预算执行页复用该口径，不另建一套余额算法。
4. 取消原“实际值”独立页面及其人工录入功能；全年实际查询并入预算执行页。
5. 人工数据继续通过“财务预算 → 批量操作 → 导入实际”入口维护，不设置独立侧栏菜单。实际明细区分人工导入与单据使用；单据使用标明14种具体单据类型，各单据独立，无报销与付款关联关系。
6. 页面展示某一时点的数据；有更新时提示刷新，金额、规则、明细保持同一版本。提交报销或付款时按现有业务规则重新校验。

## 3. P01 财务预算概览

- 保留图1的结构、工具栏、查询区和列顺序，不增加指标卡、冻结金额或在途单据数。
- 顶部保留模板管理、批量操作、搜索及更多入口；筛选保留选择团队与财年。
- 批量操作下拉保持原顺序：锁定预算、锁定预测、解锁预算、解锁预测、导出预算、导出预测、导出实际、导入预算、导入预测、导入实际。
- 实际值导入仅从上述“导入实际”入口进入；不设置独立侧栏菜单。实际明细中的批次追溯仍可进入已有导入记录。
- 表格列：勾选、操作、财年、责任团队、创建人、预算、预测、实际、模板名称、预算状态、预测状态。
- 行操作由“预算／预测／实际”改为“预算／预测／执行”；执行进入对应团队预算执行页，保留团队、财年参数。
- 金额继续采用原展示方式，概览不新增金额下钻入口。冻结与实际明细从预算执行页查询。

## 4. P02 团队预算编制

- 保留现有团队、财年、币种／金额单位、科目树、各财年月预算和保存能力。
- 预算编制与预算执行为独立页面，不设置相互切换的tab；分别从概览行操作“预算”和“执行”进入，分别打开独立工作页签，页签支持激活与关闭，页面不提供返回概览入口。
- 编制页不增加人工实际录入、冻结维护或手工修改可用额度。
- 原型标注该页复用现有编制流程；预算变化生效后，执行页通过公共数据变化机制更新。

## 5. P03 团队预算执行

### 公共区域

- 预算执行独立于预算编制，从概览“执行”进入；不显示编制／执行切换tab和返回概览入口；作为独立工作页签打开，可在顶部激活或关闭。
- 顶部：团队、财年、金额单位、数据截至时间、刷新，不展示刷新左侧的“示例”标签；月度和全年执行均不展示顶部统计卡片，筛选下方直接展示科目执行表。
- 筛选：预算归属月份、预算科目；月份按照系统财年顺序排列。科目筛选采用双栏级联样式：左栏展示一级科目，悬停一级或点击右箭头，右栏展示该一级的二级科目；点击一级或二级前的单选圆点立即生效并关闭面板，输入框展示完整选中路径，支持“全部科目”清空，点击外部或按 Esc 关闭面板。支持全部、一级和二级科目，选择一级展示该一级及全部下属二级，选择二级展示所属一级及所选二级；月度、全年和导出使用相同范围。一级行金额保留该一级完整口径，筛选二级不改变一级汇总金额。
- 视图切换：“月度执行／全年执行”。
- “科目预算执行”标题右侧常显小副标题：“本月列按所选月份统计；管控可用按生效规则计算。点击可用额度查看范围与计算说明。”
- 执行页底部不展示备注；月度实时额度与提交校验备注移至“管控可用额度”旁的 ⓘ，全年备注放在“全年科目执行”标题旁的 ⓘ，悬停、聚焦或点击查看，点击外部或按 Esc 关闭。
- 只读查询，不提供原图3的保存、取消和人工录入按钮。
- 月份默认定位当前财年的当前月份；查看历史或未来财年时使用该财年最后一个归属月，并清晰显示选择结果。

### 月度执行视图

| 字段 | 展示要求 |
|---|---|
| 预算科目 | 按一级、二级层级展示，始终展开，不提供展开／收起操作；明确收入、支出分类 |
| 本月预算 | 选中预算归属月的当前生效预算 |
| 本月实际 | 同科目、同归属月的实际使用净额；点击进入P05 |
| 本月冻结 | 同科目、同归属月的当前有效冻结；点击进入P04 |
| 管控方式 | 一级科目留空；二级科目从现有配置读取具体规则名称，含一级／二级及累计／不累计 |
| 管控可用额度 | 一级科目留空；二级科目展示按申请端口径计算的数值；点击打开C01 |

- 2026-10-28 展示调整：一级科目不展示管控方式、可用额度及期间。二级科目展示具体管控方式、数值可用额度与期间；一级管控下沿用一级科目池计算，按最新确认不展示“共享XX额度”提示，点击数值打开该池的C01。各子科目展示同一池余额不代表独立额度，不重复相加。导出一级行相关字段留空，二级行导出具体规则、管控科目、期间及数值余额。
- 本月实际／冻结与累计管控可用可能采用不同期间，必须分别标注，不能用本月列直接解释累计额度。
- 收入科目显示预算及实际；冻结与支出管控可用不适用时显示“—”。
- 无预算、无管控规则、共享额度和金额为零使用不同表达；“—”不得替代真实的0元。
- 管控可用为负时显示真实负数及超额提示；余额为零但尚未超额时不得误标为已超额。
- 不对独立管控池、父子共享额度或不同累计月份的可用额度做合计。

### 全年执行视图

- 财年预算、实际和当前有效冻结在科目执行表中展示，实际和冻结可按整个财年下钻。
- 科目树＋财年预算＋财年实际＋当前有效冻结＋财年各月份分布。
- 各月分布支持预算／实际／冻结指标切换，默认实际；固定的财年汇总三列不随指标切换。
- 年度冻结指预算归属本财年且当前仍有效的占用，按归属月分布，不累加历史查询快照。
- 点击实际／冻结的财年汇总进入全年明细；点击月份金额仅进入该月明细。返回保留指标与筛选。
- 收入科目冻结不适用，显示“—”。不展示年度可申请额度或预算结余。
- 沿用同一截至时间、版本及刷新机制；导出包含三项财年汇总与当前指标的各月分布。
- 固定科目列和表头，支持横向滚动，遵循财年2月至次年1月配置。

## 6. P04 在途冻结明细

### 筛选与汇总

- 单据类型：报销申请、付款申请、内部调账单、费用记账单、出差报销单、付款单、项目付款单、多项目付款单、固定资产付款单、报销单、项目报销单、多项目报销单、固定资产报销单、入企报销单。
- 筛选：团队、预算归属期间、费用科目、单据类型、单据状态、申请人（支持姓名／工号）、单号或单据标题。
- 状态枚举及顺序：待审批、审批中、待财务审核、待支付、已支付、支付失败。状态筛选、列表及原单详情使用相同名称；状态、来源类型以普通文字展示，不使用彩色标签。列表状态列仅展示状态文字，不展示下方当前节点或注释；导出保留状态及当前节点。
- 冻结列表按当前有效冻结余额查询，不因状态筛选而加入无冻结记录；示例数据中已支付记录归入实际，无剩余冻结，因此在冻结列表选择已支付为空。实际业务的状态与冻结释放／实际确认映射继续按现有规则核实，不仅凭状态名称重算金额。
- 汇总：当前有效冻结金额、去重单据数。
- 单据提交日期与预算归属期间是不同字段；页面以预算归属期间为额度核对条件。
- 默认只展示当前仍有效的冻结；不将历史冻结发生额混入当前冻结余额。

### 列表字段

单号、单据类型、费用科目、预算归属月、申请人、单据标题、当前冻结金额、单据状态、提交时间、命中管控科目。2026-10-28 移除在途天数展示，提交日期保留。

首列仅展示单号，不在同一单元格追加费用行、团队等副文案；申请人为“姓名（工号）”。列表不展示费用摘要；费用行／分摊行仍保留在数据及原单详情中。

### 功能与交互

- 点击单号进入R02，支持有权限时定位对应费用行；详情中展示对应单据标题及“姓名（工号）”。
- 按费用行或预算分摊行展示，一张单据跨团队、科目、月份时拆行。
- 支持查询、分页、排序、导出、刷新和返回来源页。
- 从本月金额进入时按本月取数；从C01累计冻结进入时按完整管控范围取数。
- 无详情权限时明确提示，不因可见汇总金额而自动开放单据权限。

## 7. P05 实际使用明细

### 筛选与汇总

- 筛选：团队、预算归属期间、费用科目、来源类型、单据类型、申请人（姓名／工号）、单号或单据标题。
- 来源类型：人工导入、单据使用。单据类型沿用P04的14种枚举；人工导入的单据类型不适用，显示“—”。
- 人工导入与单据类型筛选联动：选择人工导入时清空并禁用单据类型筛选；选择具体单据类型时按单据使用查询。
- 汇总：实际使用净额、人工导入与单据使用金额小计；汇总采用完整筛选范围，而非当前分页。

### 列表字段

单号、来源类型、单据类型、预算科目、预算归属月、申请人、单据标题、实际金额、实际确认日期。

首列仅展示单号，申请人为“姓名（工号）”；列表不展示费用摘要，不在单号下追加费用行或团队。人工导入记录的申请人显示导入人“姓名（工号）”，单据使用记录显示原单申请人；申请人查询和导出使用相同口径。人工导入缺少单号或单据标题时显示“—”，不得将导入批次号当成单号。

### 功能与交互

- 各类单据来源：点击单号进入该张独立原单R02，仅追溯当前单据。
- 人工导入来源：列表“人工导入”为纯文本，不可点击，不触发跳转或来源抽屉；导入数据通过已有“财务预算 → 批量操作 → 导入实际”入口维护。
- 实际确认日期反映现有业务确认口径；导入时间单独展示，不替代实际确认日期。
- 支持来源类型、单据类型、申请人及单号／单据标题查询、分页、排序、导出和返回；导出列同步单号、姓名（工号）及单据标题，不含费用摘要。页面只读，无新增、编辑和删除按钮。
- 冲销／退款如现有口径已支持，按现有规则展示负向金额，合计按净额计算。
- 所有单据独立，无报销单与付款单的关联关系；不展示关联单据列或关联详情，不通过跨单据关系合并金额。单张单据重复事件仍应避免重复统计。
- 人工导入与系统单据的重复认定规则需沿用并核对已有机制。

## 8. C01 管控额度计算说明

### 展示内容

1. 团队、所选预算归属月、数据截至时间。
2. 当前生效的管控科目和管控方式。
3. 管控期间：财年起始月至归属月，或仅归属月。
4. 管控范围预算、范围内实际、范围内有效冻结及可用额度。
5. 清楚展示计算关系；如现有计算还包含其他有效占用／调整项，一并解释，不能用简化公式替代现有业务口径。
6. 点击实际／冻结金额进入对应完整范围的P05／P04，继承同一取数版本。

面板底部不展示累计范围、共享额度及提交时重新校验的补充提示文案。

## 9. C02 实时变化与一致性

| 状态 | 原型表现 | 交互规则 |
|---|---|---|
| 初次加载 | 加载态，成功后展示截至时间 | 金额、规则、汇总使用同一取数版本 |
| 占用发生变化 | 本期不做自动检测及提示 | 用户手动刷新后更新数据 |
| 预算调整生效 | “预算额度已更新” | 刷新预算、占用和可用等相关数据 |
| 管控方式变更 | 本期不做自动检测及提示 | 用户手动刷新后更新规则和额度 |
| 刷新成功 | 更新截至时间，消除变化提示 | 保留团队、月份及科目筛选状态 |
| 刷新失败 | 保留旧数据及原截至时间，提示重试 | 不将旧数据标记为最新 |
| 下钻数据版本失效 | 提示“数据已变化，需同步更新汇总及明细” | 同步更新来源金额和目标明细，避免静默混用 |
| 空数据／无权限 | 分别展示明确状态 | 不把读取失败、无权限显示为0元 |

- 本期不实现占用变化、管控方式变更的自动检测通知，移除对应两个演示场景；保留手动刷新。
- 翻页、汇总、明细和导出应遵循同一取数版本；导出注明取数时间与筛选口径。
- 页面浏览不锁定预算；申请提交仍使用最新规则重新校验并完成占用。
- 本期提供当前时点查询，不默认提供任意历史时点余额回放。

### 工作页签规则

- 财务预算概览与其他工作页签一样支持关闭，并可从左侧“财务预算”重新打开；预算编制与预算执行按“页面类型＋团队”打开独立页签。
- 同一团队的同类页面再次打开时激活已有页签，避免重复；不同团队可同时打开。
- 页签切换保留归属月、年月视图、指标、科目筛选与未保存预算修改。
- 所有工作页签均提供关闭按钮；关闭当前页签后激活相邻页签，关闭非当前页签时保留当前页面。关闭最后一个页签后展示工作区空态，左侧菜单可重新打开页面。
- 关闭未保存预算页签时提示是否放弃修改；可关闭提示继续编辑。
- 预算编制、预算执行页内不提供返回概览按钮；冻结／实际下钻的返回用于回到所属执行视图。

## 10. 页面跳转关系

```text
P01 财务预算概览
 ├─预算编制 → P02 团队预算编制
 ├─预算执行 → P03 团队预算执行
```

## 11. 原型绘制清单与顺序

| 顺序 | 画稿 | 必须表达的场景 |

## 12. 开发前需核实的现有系统条件

这些项目不阻塞低保真原型，但需在原型中明确依赖，不擅自改变现有业务口径：

- 现有申请端余额是否完整扣除在途报销／付款，覆盖哪些状态；避免再次扣减。
- 各类独立单据计入冻结、实际及释放的状态节点；各单据按自身规则处理，不建立跨单据关联。
- 现有管控配置发生变更时的生效、重算机制，是否支持完整版本切换。
- 汇总、下钻、分页和导出是否支持同一版本；不支持时采用明确提示并同步刷新方案。
- 已有实际导入是否具备批次、操作人、原始行、撤销／纠错及重复校验记录。
- 团队汇总是否包含下级，以及各角色的金额、单据和导入记录访问权限。

## 13. 核心验收项

1. 相同查询时点、团队、科目和归属月份下，执行页与现有申请端余额一致。
2. 四种管控方式展示正确；一级共享额度不重复合计，累计范围不包含未来月份。
3. 实际／冻结的展示金额与同范围、同版本明细合计一致。
4. 数据变化不造成规则与金额、汇总与明细混用；失败时旧数据仍保留原截至时间。
5. 人工导入与单据使用来源可辨认，14种单据类型可筛选和追溯；单据独立，无关联单据字段和跨单据合并。
6. 原实际页面人工录入能力取消，人工实际通过已有导入入口维护。

## 团队预算调整申请单审批详情

- 从审批列表的详情或标题打开独立可关闭页签；同一申请单重复打开激活已有页签，不同申请单可同时打开。左侧仍选中“办公管理 / 审批”。
- 顶部保留同意、驳回、转审、取消、评论及标签操作；“取消”关闭详情页签。表单详情与审批记录可切换。
- 操作栏下不重复展示页面标题和单号；调整原因仅在单项后展示，不设整体原因栏。
- 默认“本次调整”视图只展示本次变化的科目和月份：一级科目上下文、二级科目、调整月份、原始预算、调整前、调整后、变动金额、变动率、本项调整原因及定位入口。原因同一行完整展示，不提供筛选。
- 汇总展示本单调整笔数、二级科目数、月份数、增加、减少和净调整。汇总按整张申请单计算；各笔按二级科目＋月份去重，不将父级汇总重复计入。
- 原始预算指最初编制值，调整前指提交申请时的当前预算快照，调整后指本次申请目标值；变动金额＝调整后－调整前，变动率以调整前为基数。调整前为0时新增预算展示“新增预算”，不生成无限百分比。
- “完整预算”保留财年2月至次年1月及全部科目；每个月份包含原始预算、调整前、调整后、变动金额和变动率，最后一列展示该科目本次调整原因并标明月份；固定科目列及两层表头，区分历史调整与本次调整。始终展示全年月份，不提供“仅看调整月份”；调整金额为纯文本，不提供点击查看原因及相关提示。
- 从“本次调整”的“定位完整预算”直接切换并定位对应科目、月份与调整后单元格；详情页签切换保留当前视图。
- 审批沿用原有本地模拟，处理后同步详情状态与列表并记录审批意见；不会写入真实系统或更改预算执行页金额。示例调整涉及5个科目、3个月份，增加30,000元、减少10,000元、净增加20,000元。


## 团队预算调整申请入口与填写

- 办公管理的“申请”打开独立页签，右侧白色区域展示红色预算图标与“团队预算调整申请单”入口。
- 点击入口，居中弹窗选择财年和团队，提供确认、关闭；团队使用已有预算团队，确认后打开独立可关闭申请页签，同团队复用已有页签。
- 顶部操作为取消、保存草稿、提交送审，基础信息包含标题、申请时间、申请人、申请部门、团队和财年。
- 默认展示2026-10当前月，预算归属月下拉可选2026-02至2027-01任一月份或全年，也可使用展开／收起按钮。有调整金额、未填完金额或调整原因（含已保存草稿）时，切换先提示“将清空已填写数据”；确认清空所有月份的调整金额及原因、恢复调整前金额并切换，汇总归零；取消、关闭或 Esc 保留期间及数据。没有调整则直接切换，选择当前期间不处理。收起回到展开前所选月。确认清空同步删除当前团队本地草稿，其他团队不受影响；删除失败不清空、不切换，可重试。已提交只读申请仅切换查看，不清除快照。
- 科目列固定在左侧；每月包含原始预算、调整前、调整后、变动金额和变动率。二级科目可编辑调整后金额，一级科目只读并自动汇总；差额和变动率随输入更新。
- 最右侧为每个二级科目的调整原因输入，全年展开时固定在右侧；同科目多月调整共用该原因，审批明细按月份对应展示。
- 草稿本地按团队保存，关闭重开可恢复；未保存关闭需确认；团队间编辑相互隔离。
- 至少一笔调整才能提交；金额为非负数、最多两位小数；所有变更科目均需原因，缺少时定位输入框。
- 提交确认后在原型审批列表新增记录，审批详情及完整预算读取提交快照；原申请页只读，防止重复提交。仅演示本地流程，不改动真实预算。

- 预算执行页签标题固定为“预算执行”，不带团队名称；执行使用单个页签。页内选择团队、概览其他团队执行入口均更新现有页签，不新增页签。
