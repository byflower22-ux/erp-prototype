## 原型标记配置流程（2026-10-27）

排序流程：配置标记 → 清空搜索 → 选中已保存标记 → 上移／下移 → 统一编号刷新、顺序立即本地保存 → 导出共享。首尾限制及未保存新条目禁用；表单文字修改不随排序自动保存。

正文标记开启 → 编号沿用原区域边缘位置 → 仅遮字或相撞时向附近空白处微调 → 悬停加粗区域 → 点击查看说明。无需独立标记栏，开启前后业务区及侧栏宽度不变。

工作台顶部统一入口：版本标记 → 配置标记 → 新增／编辑 → 选择标记范围（页面区域／菜单区域）→ 选择区域（页面在对应业务模块内，菜单为一级／二级菜单）→ 保存 → 统一显示标记。点选期间拦截原操作；折叠菜单隐藏子项编号，展开恢复。

进入目标业务页面 → 顶部“版本标记／配置标记” → 新增或编辑条目 → 填写迭代、类型、标题、说明及资料 → 选择页面区域（纯规则跳过）→ 点击锁定，可向上扩大或返回下一级 → 使用此区域 → 保存标记 → 即时预览。点选拦截业务点击，Esc 取消并保留编辑内容。

保存仅在当前浏览器生效。工作台 JSON 导出／导入包含页面与菜单；项目共享则导出脚本 → 更新公共 `version-marks-config.js` → 同步迭代资料与台账。预算独立页沿用模块配置与 `_当前.html` 构建。首次打开工作台自动合并旧的页面／菜单本地配置；之后以统一配置为准，已有覆盖可用“恢复项目配置”读取默认值。具体见[接入记录](版本标记接入.md)。

ERP-I003，V1.11，2026-10-27。正式系统规则以[详细需求说明](详细需求说明.md)为准，公共入口与页签行为见[公共框架接入](公共框架接入.md)。

1. 财务预算概览 → 预算：打开对应团队编制页签。收入科目允许负数，覆盖手工编制、导入预算与预算调整申请；支出沿用原校验。
2. 概览 → 执行：复用预算执行页签，按团队、财年、归属月及科目查看月度／全年预算、实际和有效冻结。
3. 实际／冻结金额 → 明细：继承来源期间及科目范围。冻结按有效分摊逐行展示，实际按流水及分摊展示，人工导入按批次原始行展示；相同单号不合并金额，导出与列表粒度一致。
4. 管控可用额度 → 额度说明 → 范围实际／冻结：科目池、期间、数据版本一致，当前可用余额＝范围预算－范围实际值－范围冻结金额，不重复扣冻结。
5. 单据明细 → 单号：打开对应类型原单的审批详情页签，关闭后返回来源明细并保留筛选；人工导入进入批次追溯。
6. 14 类业务单据：草稿不占用 → 正式提交成功冻结 → 业务／财务审批期间保持冻结 → 对应节点整单转已使用。内部调账单为财务确认成功，费用记账单为整条流程审批通过，其余 12 类为支付成功；全部有效分摊同步转换。
7. 冻结中的单据驳回／退回修改、撤回、作废或取消成功 → 全额释放；修改、保存草稿不冻结，重新提交成功按新版本重新校验并冻结。支付处理或结果未知时保留冻结并标记“结果待确认”，沿用原单状态，不新增状态枚举。反向业务沿用现行规则。
8. 办公管理 → 团队预算调整申请：选择团队与财年，填写调整后金额及原因，保存草稿或提交；提交生成审批快照。
9. 团队预算调整审批：草稿、审批中、退回、驳回、撤回不改变生效预算；整条流程审批通过时，按审批快照中的调整后金额更新对应预算，未改项不变，重复通知不重复生效。
10. 调整生效后刷新执行页及额度说明：读取生效预算重算可用余额，已有实际和冻结不因此改变。

状态定义与[审批分段图](图片/预算状态审批流转图.png)见主需求第 2 章，金额对账见第 4.2 节。规则已确认，接口联调与业务测试执行结果另行记录。

现有原型仍为本地演示；文档更新不代表已完成审批生效或生产接口开发，原型模拟能力不代替正式系统规则。

历史重建见主需求第 5 节：统一截止 T，按原单及有效提交版本逐条分类，分摊重建冻结与实际；旧汇总仅留存备查，不迁入、不补差对平。人工导入及反向业务有依据地迁入，异常单据核查；在途单据迁入后接续支付、驳回和重提，迁移重跑与实时事件不重复记账。

历史分类与冻结筛选统一沿用八种单据状态：待审批、审批中、已驳回、草稿、待财务审核、待支付、支付失败、已支付；5.2 按状态逐项解释，内部调账与费用记账仍按各自确认结果判断已使用。
