# ERP 公共框架接入（2026-10-23）

适用 ERP-I003 预算优化、ERP-I004 回单对接。按已确认范围执行：统一入口、公共左侧菜单、顶部栏和工作页签。源项目目录保留，ERP 内业务副本继续维护。

## 设计与影响范围

- 根目录 `index.html` 为统一入口；`原型/公共/` 管理公共导航、页签状态与模块通信。
- 两个模块各保留一个常驻 iframe，隔离现有全局样式与业务数据。公共框架展示唯一的导航、顶部栏及页签，嵌入时隐藏模块原有外壳；独立打开仍保留原有外壳。
- 公共菜单包括财务管理→审批确认，预算管理→财务预算、预算管控规则，办公管理→申请、审批。
- 页签复用模块现有页面身份。预算编辑页未保存时显示标记，关闭继续沿用原确认；回单列表、当前审批详情、当前文件预览分别接入公共页签。
- 切换模块不卸载、不重新加载 iframe，保留查询条件、分页及未保存编辑。页签关闭由业务模块确认后才从公共栏移除。关闭全部页签显示空态，可从菜单重新打开。
- 通信只接受对应 iframe / 父窗口消息，使用固定协议；仅传递页签元信息与导航指令，不传输业务数据。
- 本轮不修改预算计算、回单状态流转、CBS/金蝶模拟逻辑。预算独立 HTML 保留归档基线，统一入口运行接入后的源码页。归档清单仍代表迁入时基线。

## 实施步骤

1. 先测试跨模块页签合并、复用、关闭确认、选中同步及消息来源校验。
2. 实现公共框架与客户端接入协议，接入两个模块既有页面管理。
3. 验证菜单与页签联动、状态保留、预算未保存关闭、回单详情与文件预览，以及既有回单自动化测试。
4. 更新两次迭代的需求补充、流程、操作、测试记录与总台账。

## 验收边界

本轮验证的是本地原型及公共框架集成。真实付款、CBS、金蝶和权限接口不在本轮范围内。页面刷新仍沿用各模块原有数据生命周期，预算内存编辑不保证刷新后保留。
