# ERP-I004 公共框架接入补充

日期：2026-10-23。此补充与归档 PRD V1.6 一起作为本轮依据。付款／回单／金蝶状态及模拟动作沿用现有实现；新增公共导航与页签接入。共同设计见[接入方案](../公共框架接入方案.md)。

## 需求与流程

1. 从 [ERP 统一工作台](../../../index.html) 的“财务管理→审批确认”进入列表；公共顶部栏、菜单及页签与预算模块共用，模块内部不重复显示外壳。按 2026-10-23 最新要求，二级菜单选中保持深色菜单底色，使用左侧红线和红字标记，不再使用接近白色的浅红背景。
2. 列表搜索、筛选、分页沿用原有逻辑；切到预算后再返回不刷新回单页面。
3. 点击标题或审批进入公共“审批详情 · 单号”页签。沿用现有单详情页设计，打开另一单据复用当前详情页签。
4. 文件预览在公共“文件预览 · 单号”页签打开，不弹出另一个浏览器窗口；当前预览复用一个页签，保留原文件分类与模拟内容。
5. 列表、详情与预览之间切换保持各自页面 DOM；详情中选中的“表单详情／审批记录”及预览选中文件继续保留。关闭预览优先返回仍打开的详情，其次列表。
6. 关闭列表页签后仍可在菜单重新打开；跨模块及重新打开保留当前页面运行期间的查询条件。全部页签关闭显示公共空态。

## 操作说明

- 日常演示打开 ERP 根目录 `index.html`；在公共菜单进入“审批确认”。直接打开本模块 `index.html` 时仍显示原有外壳与独立窗口预览方式。
- 点击公共页签切换业务，右侧 × 关闭对应页签。回单当前详情和文件预览分别只复用一个页签，不支持同类页面同时打开多张单据。
- 示例状态仍保存于 localStorage；“重置数据”仍恢复原示例。付款、上传、CBS、金蝶与文件预览均为本地模拟。
