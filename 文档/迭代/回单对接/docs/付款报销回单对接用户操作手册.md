# 付款报销回单对接系统用户操作手册

**适用对象：** 财务人员  
**版本：** V1.0  
**依据：** 当前“审批确认”页面 Demo 及 ERP-CBS-金蝶付款回单流程

> **先看这一条：** 先看“表单状态”，再看“回单状态”和“金蝶状态”。只有列表操作栏出现的按钮才可以操作；按钮没有出现时，不要重复点击或自行补录状态。

## 1. 系统能做什么

本页面用于查看付款/报销单从审批、支付、电子回单到金蝶同步的进度。财务人员主要做三件事：

1. 审核单据，决定通过或驳回。
2. 付款后补齐回单，或处理回单拉取失败。
3. 处理金蝶同步失败或部分失败。

页面显示的是三条状态链：

| 状态 | 说明 | 常见值 |
| --- | --- | --- |
| 表单状态 | 单据当前业务阶段 | 待财务审核、已驳回、待支付、已支付、支付失败 |
| 回单状态 | 国内付款的电子回单进度 | 待拉取、已归档、拉取失败；海外付款显示“—” |
| 金蝶状态 | 付款单/凭证及附件同步进度 | 待同步、同步成功、同步失败、部分失败；未进入同步时显示“—” |

## 2. 什么时候做什么（速查表）

| 看到的状态 | 操作栏按钮 | 什么时候操作 | 操作结果 |
| --- | --- | --- | --- |
| 表单状态=待财务审核 | 审批、驳回 | 核对单据、发票、金额和收款信息后 | 审批后变为“待支付”；驳回后变为“已驳回” |
| 表单状态=待支付 | 支付 | 已确认线下/银行侧完成付款，并已拿到回单 | 变为“已支付”；国内单据同时归档回单并进入金蝶同步 |
| 表单状态=支付失败 | 支付 | 已确认可以重新付款，并已取得新的付款回单 | 重新进入“已支付”流程；不要在未确认银行结果时重复支付 |
| 表单状态=已支付、回单状态=拉取失败 | 上传回单 | CBS 没有返回回单，或页面提示需要人工补传 | 回单变为“已归档”，随后进入金蝶同步 |
| 表单状态=已支付、金蝶状态=同步失败/部分失败 | 同步金蝶 | 已确认付款和回单无误，需要重试金蝶 | 金蝶变为“同步成功”；部分失败只重试失败对象 |
| 已驳回，或三条链路均无待处理状态 | 无处理按钮 | 只需查看、留档或跟进申请人 | 不要强行处理；可看详情和日志 |

## 3. 进入页面和查找单据

### 3.1 进入

1. 打开付款报销管理系统。
2. 左侧进入 **财务管理**，打开 **审批确认**。
3. 列表默认显示有权限查看的单据。

### 3.2 查找

- **关键词搜索：** 输入标题、单号、申请人或申请部门，点击搜索按钮或按回车。
- **状态筛选：** 可同时选择表单状态、回单状态和金蝶状态。例如：选择“已支付 + 拉取失败”，只看需要补传回单的国内付款。
- **时间筛选：** 可按创建时间或流程审批通过时间选择快捷区间，也可以填写开始日期和结束日期后点击“查询”。
- **其他条件：** 可按单据类型、是否涉海外、是否有发票、付款主体、收款方类型筛选。
- 修改任一筛选条件后，列表会回到第一页。找不到单据时先清除筛选，再用单号搜索。

## 4. 审核单据

### 4.1 审批通过

**什么时候做：** 表单状态为“待财务审核”，且资料和金额核对无误。

1. 在操作栏点击 **审批**；也可以先点 **详情**，在详情页操作。
2. 查看申请人、申请部门、付款主体、单据类型、金额、发票和内容。
3. 确认后提交。
4. 结果应为：表单状态变为 **待支付**，并记录审批时间。

### 4.2 驳回

**什么时候做：** 资料不完整、金额或发票不一致、收款信息有误，或需要申请人补充说明。

1. 在操作栏点击 **驳回**。
2. 在“驳回原因”中写清楚需要修改的内容，例如“发票金额与报销金额不一致”。
3. 提交后确认表单状态变为 **已驳回**。

> 驳回原因必填。已驳回单据不会继续进入支付、回单或金蝶同步流程。

## 5. 支付并归档回单

### 5.1 国内付款

**什么时候做：** 表单状态为“待支付”或“支付失败”，并且已从银行或付款渠道确认本次付款结果为成功。

1. 点击 **支付**。
2. 核对提示中的单号和付款信息。
3. 填写 **回单号**。
4. 上传 **回单文件**，至少 1 个、最多 9 个。
5. 可在“备注”中写明付款日期、线下核对情况等，确认提交。

提交后应看到：

- 表单状态：**已支付**；
- 回单状态：**已归档**；
- 金蝶状态：系统自动同步，成功时为 **同步成功**，失败时显示 **同步失败**，需要再做“同步金蝶”。

> **不要做：** 未确认银行最终结果时不要重复点击“支付”。“支付失败”也要先确认失败原因和重新付款结果，再上传新的回单。

### 5.2 海外付款

**识别方式：** “是否涉海外”为“是”，且付款主体为海外主体（当前 Demo 典型主体为 `Sands Bosum Business Pte. Ltd`）。

1. 在表单状态为“待支付”或“支付失败”时点击 **支付**。
2. 确认已完成海外付款；不需要填写回单号，也不需要上传回单文件。
3. 提交后系统直接进入金蝶同步。

海外付款的回单状态显示 **—**，CBS 交易流水号也不适用；这是正常情况，不要按国内付款补传回单。

## 6. 补传回单

**什么时候做：** 表单状态为“已支付”，回单状态为 **拉取失败**，且操作栏出现“上传回单”。

1. 点击 **上传回单**。
2. 填写回单号。
3. 选择 1–9 个回单文件。
4. 可填写备注，例如“CBS 未返回电子回单，人工补传”。
5. 提交后检查回单状态是否变为 **已归档**。

归档成功后，系统会自动发起金蝶同步。若金蝶状态变为“同步失败”或“部分失败”，继续按第 7 节处理。

常见校验提示：

- “请填写回单号”：回单号为空，补齐后再提交。
- “请上传回单文件”：没有选择文件，至少选择 1 个。
- “回单文件最多上传9个”：减少文件数量后再提交。

## 7. 同步金蝶

**什么时候做：** 表单状态为“已支付”，并且满足以下任一条件：

- 国内付款的回单状态为“已归档”；
- 海外付款不需要回单；
- 金蝶状态为 **同步失败** 或 **部分失败**，操作栏出现“同步金蝶”。

### 7.1 同步失败

1. 点击 **同步金蝶**。
2. 查看弹窗提示，确认可以重试。
3. 提交同步。
4. 检查金蝶状态和金蝶编码。

### 7.2 部分失败

部分失败表示拆分单据或附件中只有一部分失败。按页面提示先确认已成功同步的对象无需重复处理，再点击 **同步金蝶** 重试失败对象。

## 8. 查看详情、文件和日志

### 8.1 详情

点击 **详情** 可查看：单号、申请人、付款主体、金额、表单状态、回单状态、金蝶状态、CBS 流水号、金蝶编码、状态时间和当前失败原因。详情页也会显示当前可用的处理按钮。

### 8.2 文件预览

在详情页点击 **文件预览**，可以查看流程附件、发票和回单。回单文件来自 CBS 自动拉取或财务人工上传；预览页面中的文件内容是当前 Demo 的本地模拟展示。

### 8.3 操作日志

点击 **日志** 查看完整记录，重点核对四列：

- 操作时间
- 操作人
- 操作节点
- 备注

遇到争议或重复处理时，先查看日志，再决定是否重试。

## 9. 常见问题和处理方式

| 问题 | 处理方式 |
| --- | --- |
| 看不到“支付”按钮 | 确认表单状态是否为“待支付”或“支付失败”；其他状态不可支付。 |
| 国内付款回单状态为“待拉取” | 等待系统按流程拉取；未显示“拉取失败”前不要重复上传。 |
| 回单状态为“拉取失败” | 核对失败原因，取得回单号和文件后使用“上传回单”。 |
| 金蝶状态为“同步失败” | 先看失败原因和日志，确认付款/回单无误后使用“同步金蝶”。 |
| 金蝶状态为“部分失败” | 按提示只重试失败拆单或附件，不要重复创建已成功对象。 |
| 误点了操作或提交失败 | 以页面提示为准；重新打开详情核对状态和日志，不要连续重复提交。 |
| 筛选后没有结果 | 清除筛选，再按单号或标题搜索；检查日期范围是否填反。 |

## 10. 财务人员每日检查清单

### 开始处理前

- [ ] 先筛选“待财务审核”，完成当日审核。
- [ ] 再筛选“支付失败”，确认是否需要重新付款。
- [ ] 再筛选“回单状态=拉取失败”，集中补传回单。
- [ ] 最后筛选“金蝶状态=同步失败/部分失败”，完成同步重试。

### 每笔单据完成后

- [ ] 表单状态、回单状态、金蝶状态与实际业务一致。
- [ ] 国内付款有回单号和回单文件；海外付款回单状态为“—”。
- [ ] 金蝶同步成功时已生成金蝶编码。
- [ ] 失败单据已查看失败原因和操作日志。

## 11. 使用边界

当前页面是本地 Demo：操作只在当前浏览器页面内模拟，刷新页面会恢复初始示例数据；不会真实调用 CBS、上传文件到服务器或写入金蝶。正式上线时，以公司实际权限、接口和文件归档规则为准。
