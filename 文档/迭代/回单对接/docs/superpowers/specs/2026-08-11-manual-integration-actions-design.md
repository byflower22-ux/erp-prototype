# 审批确认页人工处理操作设计

## 目标

在现有“审批确认”页面中，为 CBS 与金蝶异常流程提供可操作的本地模拟入口，并在详情中保留完整处理时间线。页面不调用真实 CBS、文件归档或金蝶接口。

## 操作范围

### 人工确认支付结果

- 适用于表单状态为“查询超期”的单据。
- 操作弹层要求选择“支付成功”或“支付失败”，并填写确认说明。
- 确认成功后：表单状态更新为“已支付”；回单状态更新为“待拉取”；金蝶状态保持“待同步”。
- 确认失败后：表单状态更新为“支付失败”；回单状态保持“待拉取”；金蝶状态保持“待同步”。

### 人工上传回单

- 适用于回单状态为“拉取超期”或“待人工上传”的单据。
- 本地选择文件并填写回单号；不上传服务器，仅展示文件名作为模拟归档凭据。
- 提交后回单状态更新为“已归档”；如金蝶状态仍为“待同步”，保留该状态以等待后续同步。

### 重新同步金蝶

- 适用于金蝶状态为“同步失败”或“待人工处理”的单据。
- 操作弹层要求填写重试说明；本地模拟重试成功。
- 提交后金蝶状态更新为“同步成功”。

## 操作入口与限制

- 表格新增“处理”操作按钮，点击后仅展示当前单据可用的操作；无可用操作时显示“暂无待处理事项”。
- 详情弹层增加“处理记录”时间线和相同的操作入口。
- 不满足状态前提的操作不得显示或执行。
- 每次操作都更新状态时间，并写入时间线：操作类型、说明、操作者（当前登录用户）和时间。

## 数据与展示

- 每条单据增加 `timeline` 数组；初始数据有系统节点，例如“付款指令提交”“CBS支付结果确认”“回单任务创建”。
- 详情中依序显示基础信息、三类状态、处理记录时间线。
- 表格的操作按钮根据状态实时更新，状态筛选、分页和详情在操作后立即重新渲染。
- 所有状态更新仅保存在当前浏览器页面内；刷新页面后恢复为初始模拟数据。

## 验收

1. 三类操作只在对应异常状态下出现，提交后按上述规则更新状态。
2. 操作弹层具备字段校验、取消、提交、Escape 关闭和焦点恢复。
3. 每次成功操作均产生可见时间线记录与提示消息。
4. 原有搜索、筛选、展开、分页、详情和状态颜色保持可用。
