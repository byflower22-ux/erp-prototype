# CBS 与金蝶状态追踪改造设计

## 目标

将“审批确认”列表页扩展为付款后的 CBS 回单与金蝶同步跟踪界面。保留现有“表单状态”字段、筛选和展示，不改变其语义；新增回单状态和金蝶状态两条独立状态链。

## 状态模型

- 表单状态：沿用现有值与现有筛选逻辑。
- 回单状态：待拉取、已归档、拉取超期、待人工上传。
- 金蝶状态：待同步、同步成功、同步失败、待人工处理。

每张模拟单据新增 `receiptStatus` 与 `kingdeeStatus` 字段。状态筛选遵循与现有表单状态相同的“全部或精确值”组合规则。

## 页面改造

1. 在筛选区的表单状态之后新增“回单状态”和“金蝶状态”两行筛选芯片。
2. 在表格的 CBS 交易流水号之后新增“回单状态”和“金蝶状态”列；表单状态列保持原位和原名称。
3. 在详情弹层中新增这两个状态字段，置于表单状态之后，便于按付款、回单、金蝶顺序阅读。
4. 为两条新增状态使用明确的颜色语义：成功为绿色、待处理为琥珀色、失败/超期为红色、人工处理为紫色。

## 验收与边界

- 现有表单状态筛选结果不能因本改造改变。
- 三个状态筛选可以组合，且任一变化均回到第一页。
- 本地 24 条数据覆盖回单状态与金蝶状态的全部枚举值。
- 详情、表格与筛选显示同一份状态字段；未提供值显示 `--`。
- 不接入 CBS、金蝶接口，不新增真实的拉取、上传或同步动作。
