# 付款报销单列表页复刻设计

## 目标

根据参考截图，创建一个可在本地直接打开的财务管理后台页面。页面使用模拟数据呈现报销单与付款单，并提供可用的搜索、筛选、分页、详情和内容展开交互。

## 技术与交付

- 使用原生 HTML、CSS 和 JavaScript，不依赖构建工具、网络资源或后端接口。
- 交付一个入口 HTML 文件及按职责拆分的样式、脚本文件；直接双击入口 HTML 即可使用。
- 视觉以 1440px 以上宽屏为优先目标；小屏幕时保留完整桌面布局，表格区域可以横向滚动。

## 页面结构

1. 顶部白色工具栏：菜单、品牌标识、通知图标及右侧快捷入口。
2. 深蓝色左侧导航：财务管理处于展开且选中状态，展示与截图相符的菜单层级。
3. 内容区顶部：面包屑/标签页、页面工具按钮及关键词搜索框。
4. 筛选区：表单状态、创建时间、单据类型、是否涉及海外、是否有发票、付款主体等条件。
5. 单据表格：展示单号、标题、申请时间、申请人、部门、付款主体、内容、金额、状态与状态时间等字段。
6. 右下角浮动帮助与客服联系入口。

## 交互与数据

- 在脚本中维护至少 20 条本地单据数据，包含“报销单”和“付款单”、不同状态、日期、金额与内容。
- 搜索框按单号、标题、申请人、部门、内容进行不区分大小写匹配；回车和搜索按钮均会执行搜索。
- 表单状态、创建时间、单据类型、海外标记、发票标记和付款主体可组合筛选；“全部”清除对应维度限制。
- 创建时间快捷项包括今天、昨天、近 7 天、本月、上月、本季度、上季度、本年、去年；按钮依据浏览器当前日期计算范围。
- 表格内容列默认截断；点击该单元格的展开按钮可查看完整文本，再次点击收起。
- 每行“详情”按钮打开模态弹层，展示该单据的主要字段和完整内容；遮罩、关闭按钮与 Escape 键均可关闭。
- 分页默认每页显示 8 条；支持首页、上一页、页码、下一页、末页，并在筛选结果变化后回到第一页。
- “刷新”按钮重新以当前条件渲染数据，并给出轻量提示；“更多”按钮打开本地菜单，仅显示演示操作，不修改数据。
- 左侧菜单可折叠/展开，二级菜单项可切换高亮；帮助与客服浮钮显示本地提示。

## 视觉规范

- 主色使用截图中的深蓝侧栏、珊瑚红操作色、浅灰分隔线和白色内容底。
- 使用系统中文无衬线字体，控制文字大小与行高，使筛选区紧凑、表格信息密度接近参考图。
- 使用 CSS 绘制简单图标与状态点，避免引入外部图标库；保留统一的圆角、边框和悬停反馈。
- 各交互元素具备键盘焦点样式；模态框使用 `role="dialog"` 和焦点管理的基本实现。

## 错误处理与边界

- 没有匹配结果时显示空状态与“清除筛选”操作。
- 无效页码自动回到现有页范围；在单页结果下禁用相应分页按钮。
- 缺失可选字段时以 `--` 展示，避免页面错位。

## 验收

1. 在本地打开入口页后，整体布局、色彩、间距和信息层级与参考截图相似。
2. 搜索、任意筛选组合、内容展开、详情弹层、分页、刷新、更多菜单及侧栏交互均可正常使用。
3. 不依赖网络请求或第三方资源，浏览器控制台无 JavaScript 错误。
