## 当前业务归属

- 项目管理：我的项目日程（默认打开）、项目分析、项目人效分析。
- 订单管理：当前演示仅项目交付单，详情默认项目交付Tab。
- 师资与教练管理：咨询师列表、默认及逐月固定人工配置；项目经理等非咨询师固定人工也在此维护（Q20）。
- 移动端：首页应用“项目日程”，仅本人逐日填写，无管理员、日志及项目详情跳转。
- 导入：人效仅奖金；项目五种费用。AI旧通用工资模板属于待整改旁路，见需求D10。
