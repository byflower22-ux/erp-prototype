# 龙虾纯对话与双 Sheet Excel 修订

日期：2026-11-09。迭代：ERP-I005。状态：前端实现及本地验证通过。

用户明确：Excel由龙虾直接回复，不用点击生成；一个Excel包含所有类型，人员固定成本一个Sheet，项目一个Sheet；龙虾采用纯对话，支持输入和选择文件。本修订取代[上一版生成向导](Excel录入修订.md)，保留前版验收证据。

## 当前交互

顶部“模拟小龙虾” → 输入“录入2026年11月核算数据”并发送 → 龙虾直接回复 Excel 附件 → 下载后填数保存 → 同一对话选择文件并发送 → 龙虾说明涉及类型、填写条数及差异 → 回复“确认导入”后整本一次性写入；回复“取消”则不写入。无生成／读取／导入按钮，无类型或月份表单。附件的下载操作仅取得已回复的文件。

| Sheet | 覆盖类型 | 金额输入列 |
|---|---|---|
| 人员固定成本 | 月固定人工、人员月度奖金 | F：固定人工；H：奖金 |
| 项目核算数据 | 项目人员提成、项目异常费用、项目固定成本分摊 | J：对应费用金额 |

只有两个可见工作表，无隐藏第三表；内部模板标识位于人员页隐藏第4行。仍覆盖原五类，不扩展收入比例、大客户经理提成及项目年终奖分摊；这三项按原方案在项目设置维护。人员奖金仅计个人成本。

工作表预填人员／项目／角色／月份／原金额并锁定，黄色列为空且可编辑；空白不处理、0覆盖为0。允许整行排序，拒绝增删记录、身份／表头／结构修改、公式（含缓存结果）、文本／日期／负数。文件最大5MB。模板登记及版本、全底账指纹须一致，已结月份或影响后续已结月的历史期间禁止写入。旧单类型模板须重新索取新版。

同一文件涉及多个类型时，先校验全部，再在内存构造各类型新状态，全部成功才持久化一次，任何错误均不部分写入。各类保留独立批次，共同记录 sourceFile、templateId、excelWorkbookId；同一预览重试幂等。数据在其他窗口更新或本地保存失败时，以对话报错，不提示成功。

文本、文件均在同一对话发送；附文件时优先校验该文件，即使同时输入确认文字也不会直接写入。会话历史在当前页面运行期间保留；刷新后历史清空，但模板登记保留，仍可直接上传原模板。待发文本、已选文件及待确认预览关闭时提示放弃；取消关闭保留，确认放弃清空待发状态。关闭或切换身份后的异步返回不写入。
