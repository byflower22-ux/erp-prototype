# 项目管理优化流程说明

迭代：ERP-I005。日期：2026-11-09。状态：已按用户批准设计实现前端交互 Demo；真实接口、AI识别及文件接收服务待联调。来源见[建设计划](来源资料/项目与人员核算建设计划_2026-11-06.md)，后续决议见[Demo 确认记录](Demo确认记录.md)。

## 业务流程

### 工时填写与 AI 辅助

本人进入 App／Web 项目日程 → 手工填写、复制，或上传日程／聊天截图及粘贴文字 → 小龙虾返回候选与疑问 → 编辑按天草稿 → ERP 校验身份、项目成员、必填、时长、重复及重叠 → 本人确认提交 → 正式工时直接生效并参与核算。

Q04 已确认填写精度为 0.5 小时；提交前检查本人跨项目／角色合计，日合计超过 8 小时、月合计超过考勤标准工时或非工作日时拒绝提交并提示原因。考勤日历包含节假日与调休；编辑按替换原记录后的总量校验，不允许通过分多笔填报绕过限制。

草稿不参与核算；缺日期、项目或时长时待补，不猜测。计划须确认实际发生。同一投入跨角色不能重复归集。未结月可修改／删除并留痕，已结月只读，反结账后才能调整；存在后续已结月份时，先从后往前反结账，历史期间也禁止写入；提交、修改共享版本，防止双端静默覆盖。

### 五类模板生成与导入

授权用户在小龙虾对话提出录入请求及期间 → ERP 返回项目／人员／角色／月份、锁定及版本 → 小龙虾直接回复带批次和行标识的双Sheet Excel（人员固定成本／项目核算数据，覆盖全部五类） → 用户下载只填金额 → 上传回小龙虾 → 固定程序读数 → ERP 预校验 → 显示新增／更新／空白／异常及原值、新值、差额 → 用户回复“确认导入”指定预览版本 → ERP 再次校验后整本一次性写入 → 返回批次及结果。

空白不处理，0 表示设为 0；相同提交重试幂等。身份篡改、越权、公式金额、月结锁定或版本冲突应明确拒绝或返回异常。文件变化后重新预览；事务边界按来源推荐在接口评审中固化。ERP 查询导入记录，不增加五类模板上传下载页。

### 核算与月结

项目预计费用维护：财务进入项目详情“核算设置” → 逐月填写大客户经理提成、项目年终奖分摊等预计费用 → 校验期间、权限和月结锁定 → 保存月度金额 → 系统汇总项目预计总额并参与各月核算。Q02 已确认手工分月，不从总额自动均分；不新增五类模板的 ERP 上传页面。

汇总月度交付收入、有效比例、正式工时、月工资、提成奖金、实际费用及预计费用 → 检查缺失和异常 → 固定程序归集及人工分摊 → 项目与咨询师试算 → 财务核对来源和样本账 → 财务月结 → 保存输入／规则／结果快照并锁定 → Web 看板及统一指标接口查询。

Q03 已确认：人员奖金按人员／月份归入个人成本，不要求项目关联，不自动计入项目；项目年终奖分摊由财务另行按项目／月份维护。两类记录分别取数，不因导入人员奖金自动生成项目分摊。

已结源数据变化时形成差异；需要调整时，由有权限人员说明原因并反结账 → 明确后续月份影响 → 调整及重新核算 → 核对并重新月结。Q01 已确认按项目累计利润差额计税，本月允许负数税额回调；跨月历史调整应纳入后续月份影响检查。Q06 已确认个人盈亏平衡点＝（固定人工＋提成＋奖金）÷［1－（税费＋管理费）÷当月交付金额］，不能再用旧 Excel 的行公式作为试算标准。

### 历史补齐

区分项目核算与咨询师核算的历史项目范围 → 补齐工资、提成、奖金、比例及预计费用月度归属 → 按人员／项目／月份补录历史估算工时并标识来源 → 校验重复与范围 → 财务对算 → 依适用月结规则形成快照。历史工时不拆造具体日期，不增加审批环节。

## 原型接入流程约束

页面就绪后，从公共菜单导航到业务模块，由模块发布页签快照，公共框架同步当前页签和菜单高亮。切换模块保留查询及编辑状态，关闭未保存页面由业务模块确认；具体业务入口和页面标识在需求确认后登记。

龙虾纯对话输入请求及月份 → 直接回复双Sheet .xlsx附件（全部五类）→ Excel黄色列填数保存 → 选择文件并发送 → 校验模板登记、月份/身份/版本及非负数值 → 对话内差异说明 → 回复“确认导入”后整本一次性写入并保存来源/批次，或回复“取消”不写入。无生成按钮、类型月份表单及页面金额录入表格。文件只在浏览器处理，正式小龙虾服务另联调。
