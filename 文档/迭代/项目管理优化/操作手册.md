# 项目管理优化 Demo 操作手册

迭代：ERP-I005。日期：2026-11-09。适用已批准的前端交互 Demo。

## 打开与示例

打开 [ERP 工作台](../../../index.html)。左侧项目管理包含“我的项目日程、项目列表”，财务管理新增“核算工作台”，核算分析包含“项目分析、咨询师分析”。可重复点击菜单复用页签，切换预算/回单会保留状态。

也可直接打开 [独立原型](../../../原型/项目管理/项目管理优化/index.html)。顶部辅助栏切换演示身份/人员、手机日程、模拟小龙虾或重置示例。默认财务管理员、林予安、2026-11，金额单位元。

示例为虚构的3项目/3人员及2026-09至2026-11数据。九/十月使用单独标识的历史月度估算工时，不伪造具体日期。11月6日休息、7日调班仅为公司日历示例。11月许映舟故意缺工资，用于演示补齐后月结。

## 日程与 AI 草稿

1. “我的项目日程”切换日/周/月；选择日期和项目，新增日程，填写项目角色与工时。也可选择起止时间，由程序计算时长。
2. 最小0.5小时，同人跨项目每日最多8小时、每月不超过考勤标准，非工作日拒绝提交。无工时审批。编辑已提交记录按替换后总量校验，支持删除。
3. “保存草稿”、复制当日/本周、多日填报均先生成草稿；草稿不计核算。确认无误后“提交全部草稿”，错误须先编辑修正。
4. “AI 草稿 · 模拟”选择材料或粘贴文字，再选预设场景。缺少时长须补齐，确认实际发生后才可提交；也可仅保存草稿。Demo 不调用识别服务。
5. “手机日程”展示手机宽度日视图，复用同一状态；真实390宽度浏览用独立入口。移动端只演示日程和AI。

## 项目设置

“项目列表 → 查看详情”查看合同/交付收入，在核算设置中按月份维护成员收入比例及大客户经理提成/项目年终奖分摊。比例合计允许低于100%，不得超过100%；预计费用逐月手填，总额自动汇总。切换月份或关闭有修改的表单会提示放弃确认。

人员奖金只计个人成本，不自动生成项目年终奖分摊。项目工资按“月固定人工÷月标准工时×项目工时”分配；个人仍计整月人工，未分摊部分留在个人成本。

## 龙虾对话与 Excel 导入

1. 顶部打开“模拟小龙虾”，在输入框发送“录入2026年11月核算数据”。龙虾直接回复 Excel 附件，点击附件下载；没有类型／月份表单或生成按钮。月份通过对话说明，未提到时采用当前页面月份并在回复中写明。
2. 一个 .xlsx 包含全部五类数据，只有两个可见 Sheet：**人员固定成本**（固定人工、人员奖金）和 **项目核算数据**（项目人员提成、异常费用、固定成本分摊）。人员／项目／角色／月份／原金额已预填，黄色金额列留空可编辑。人员页 F 列填固定人工、H 列填奖金；项目页 J 列填写各费用类型的金额。
3. 在 Excel 中只填需要变更的金额并保存。空白不处理，**0** 明确覆盖为0；仅支持非负数值，拒绝公式、文本和日期。不改预填信息、表头、工作表或记录数量。工资／奖金按人月，提成按项目／人员／月，异常费用和固定成本按项目／月。人员奖金只计个人成本。
4. 回到同一对话，点击“选择文件”，选择填写后的 .xlsx（最大5MB），点击“发送”。龙虾在对话里回复期间、填写条数和涉及类型，可展开“查看导入差异”；此时尚未写入。回复 **确认导入**，整份文件一次性持久化，所有涉及类型共同成功；回复 **取消** 则不写入。文件和文字也可同时发送，附文件的消息优先进行文件校验。
5. 校验错误、版本冲突或保存失败直接以对话回复。修改文件后可重新选择发送；模板输出后底账已变化时，需要重新索取模板。模板登记保存在当前浏览器，刷新后可直接上传原文件，无需先索取另一份；切换浏览器、重置示例后须重新索取。旧单类型模板须换新版。
6. “核算工作台 → 导入记录”保留每个类型的实际文件名和批次，同一工作簿共用来源编号。导入按值替换，同一预览重试不累计。ERP业务页不另增模板上传页。会话历史在本页运行期间保留，刷新后重新开始；有未发送文字／文件或待确认预览时，关闭会提示放弃，取消关闭则保留。

月结演示：发送“录入11月核算数据”，下载回复的 Excel，在 **人员固定成本!F8**（许映舟固定人工）填写 **11000**，其余留空。保存后选择文件并发送，回复“确认导入”，补齐11月工资，原有两人工资保持。模板输出后请避免同时在其他窗口修改底账。

## 核算、月结与反结账

核算工作台的“核算数据”按类别查询并查看来源；财务可授权纠错，填写新金额和原因，保留修订日志。

“月结”页签查看缺输入清单 → 完整性检查/试算 → 确认月结。程序保存输入、规则与结果快照，并锁定当月及影响后续已结月份的历史写入。仅零收入导致无法测算盈亏平衡的提示不阻止月结，必要历史输入缺失会阻止。

需要调整时，从最晚已结月开始“反结账”，填写原因，再修改/试算/重新月结。不能直接修改历史数据使后续已结结果失真。

## 分析与来源

项目/咨询师分析选择月份、实体和当月/累计。多实体汇总不相加盈亏平衡点，选择单体查看。个人盈亏平衡点保持所选当月口径；累计净利率/饱和度按合计分子分母计算。

- 项目收入使用确认交付金额，合同/回款/应收分别展示。所得税按正累计税前利润的15%算累计税额，再减前期累计税额，亏损月可负数回调。
- 个人盈亏平衡＝（固定人工＋提成＋奖金）÷［1－（税费＋管理费）÷当月交付金额］，使用实际费用字段。收入为0、缺必要输入或分母非正显示无法测算。
- 来源明细与当前范围一致，累计范围显示截至所选月各月来源；咨询师项目构成的来源链接定位对应月份。导出CSV沿用筛选和累计范围。
- 项目分析按2026-02起立项筛选；人员仍核算2026-02起参与的全部项目。示例历史范围仅9—11月，完整历史迁移待正式接口。

## 保存、身份与版本标记

本地数据保存在当前浏览器，刷新后保留。未保存关闭需确认；存储空间不足或检测到其他窗口修改会明确报错并保留表单，不会提示保存成功。遇到冲突先刷新，不要同时在多个窗口改同一演示数据。

“咨询师本人”仅演示所选人员的日程；“授权管理人员”只读；“财务管理员”可维护核算。顶部切换用于演示，不能替代生产身份认证。

统一版本标记选择ERP-I005可查看5个页面新增范围；预算原13项保持。旧浏览器个人标记配置继续保留，如缺新增项可在“配置标记”中先导出备份，再“恢复项目配置”。重置示例只重置项目Demo底账，不影响预算/回单数据或版本标记。

本原型已支持本地真实Excel下载和上传读取；龙虾对话及AI识别仍为演示，不连接真实ERP或小龙虾服务；程序计算和交互通过的证据见 [Demo验收记录](Demo验收记录.md)。
