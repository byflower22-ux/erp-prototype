| Q01 | 项目所得税跨月 | 采用累计利润计税，允许回调：累计所得税＝MAX（项目截至本月累计税前利润，0）×15%；本月所得税＝本月累计所得税－上月累计所得税，本月税额可为负数 |
| Q02 | 预计费用月度分配 | 大客户经理提成、项目年终奖分摊等预计费用由财务逐月手工填写，系统汇总项目预计总额；不采用总额自动按月均分，不新增五类模板的 ERP 上传页面 |
| Q03 | 人员奖金归属 | 人员奖金只计入该人员当月核算成本，不要求指定项目，不自动归集至项目成本；项目端另行维护“项目年终奖分摊”，两者分别维护，不将人员奖金再次自动计入项目 |
| Q04-1 | 工时填写精度 | 最小填写单位为 0.5 小时（30 分钟），填写工时按 0.5 小时的整数倍校验 |
| Q04-2 | 工时提交边界 | 严格限制：同一人员当天各项目／角色合计不得超过 8 小时，当月合计不得超过考勤标准工时，非工作日不允许提交；仍校验重复记录、明确时间重叠及月结锁定，不增加工时审批或加班分类 |
| Q06 | 个人盈亏平衡点 | 采用用户明确给出的公式：（固定人工＋提成＋奖金）÷［1－（税费＋管理费）÷当月交付金额］。按所选人员当月的实际金额取数，不将分母写死为 76.7%；交付金额为 0 或分母不大于 0 时返回无法测算的原因 |

## 确认进展与适用说明

本轮已列出的 8 项范围及业务问题全部确认（工时精度与提交边界分两次确认）。用户已选择“按设计开始制作 Demo”，[设计](Demo原型设计.md)已批准，实施与验证见[验收记录](Demo验收记录.md)。正式接口能力盘点与生产业务验收另行开展。

Q04-2 的工作日以 ERP 公司考勤日历为准，包含节假日和调休，不以周一至周五直接替代。提交前对本人已有正式记录与本次提交内容一起检查日／月合计；编辑时按替换原记录后的合计校验。历史月度估算仍不伪造日记录，按已有历史补录方案维护，不能对无具体日期的历史记录虚构日校验。

Q01 示例：首月税前利润 10,000 元、次月 -4,000 元，则累计所得税分别为 1,500 元、900 元，次月所得税为 -600 元。累计利润亏损时累计所得税为 0，不能成为负数；项目首个核算月的上月累计所得税为 0。咨询师核算仍采用既有个人月度所得税规则，本次不改变。

Q05 的真实 ERP 接口与小龙虾服务能力盘点作为正式联调事项保留；D01 已明确本次 Demo 使用前端模拟，不等待真实接口后才能开展设计。
