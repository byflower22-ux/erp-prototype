# 项目管理优化 Demo 实施计划

日期：2026-11-09。依据：[已获用户批准的原型设计](Demo原型设计.md)。状态：已完成，证据见[Demo验收记录](Demo验收记录.md)。

目标：在 ERP 工作台中交付 Web 与移动端日程、项目核算设置、财务工作台及两张分析看板，全部使用同一示例底账与实际计算。

架构：沿用普通脚本与公共客户端；一个 project 模块 iframe 保留页面状态。模块拆分为核心模型、业务页面、样式和控制器；核算、工时、导入及月结的状态规则集中在核心模型。

## 全局约束

- 采用已确认 D01—D03、Q01—Q04、Q06；正式服务及 AI／小龙虾模拟需明确标识。
- 业务模块一个常驻 iframe，复用公共菜单、顶部栏、页签及版本标记。二级选中浅红背景、红线、红字。
- 工时 0.5 小时步进；日合计≤8，月合计≤考勤日历标准工时，非工作日禁止提交。
- 人员奖金仅计个人成本；预计费用手工分月；项目所得税累计差额法；个人盈亏平衡严格按用户原式取数。
- 不覆盖既有预算／回单源码基线或默认标记；验证公共框架影响。
- 交付证据位于本迭代目录，临时产物放 `.cache/`，不提交缓存。
