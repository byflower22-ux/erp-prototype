# Demo 模型与页面接口

本文件为实施契约，属于已批准设计的技术拆分，日期 2026-11-09。

`model.js` 以 UMD 导出全局及 CommonJS `ProjectModel`。金额为元的数字，统一到分；比例为 0—1。

## 状态

`seed()` 返回：

```js
{
  revision: 1,
  months: ['2026-09','2026-10','2026-11'],
  projects: [{id,name,type,status,ownerId,contract,startDate,receivable}],
  people: [{id,name,joined,role}],
  members: [{projectId,personId,role}],
  calendar: {'2026-11': {days:['2026-11-02'],standardHours:168}},
  delivery: [{id,projectId,month,amount}],
  receipts: [{id,projectId,month,amount}],
  actualCosts: [{id,projectId,month,category,amount}], // business / management / travel
  salaries: [{id,personId,month,amount}],
  commissions: [{id,projectId,personId,month,amount}],
  bonuses: [{id,personId,month,amount}],
  expenses: [{id,projectId,month,category,amount}], // accountManager / exception / yearBonus / fixed
  ratios: [{id,projectId,personId,month,ratio}],
  times: [{id,personId,projectId,role,date,hours,start,end,status}], // draft / submitted; start/end 可空
  historicalTimes: [{id,personId,projectId,month,hours,source:'历史估算'}],
  batches: [], closed: {}, audit: []
}
```

示例稳定标识：项目 p1、p2、p3，人员 u1、u2、u3；默认月份 2026-11。所有项目及人员为虚构。示例包括零收入项目、个人缺输入和跨月亏损，初始所有月份未结。

## 纯函数

错误使用 `throw new Error(中文原因)`，转换返回新状态，不修改输入。所有写操作增加 revision，登记 audit。UI 负责授权身份演示，模型统一校验期间锁定与版本。

- `round(value)`：金额舍入到分。
- `projectResult(state, projectId, month)`：`{id,month,income,costs:{business,management,travel,tax,accountManager,commission,salary,exception,yearBonus,fixed},totalCost,pretax,tax,net,margin,breakEven,hours,contract,received,receivable,missing:[],sources:[],cumulative:{income,received,totalCost,pretax,tax,net,margin,breakEven}}`。`costs.tax` 为收入的3.3%，结果 `tax` 为所得税。无法测算 `margin/breakEven` 为 null，缺必要输入时 missing 列原因，不当成完整核算。
- `personResult(state, personId, month)`：`{id,month,income,costs:{tax,salary,commission,bonus,management},totalCost,pretax,tax,net,margin,breakEven,hours,days,standardHours,saturation,allocatedSalary,idleSalary,missing:[],sources:[],projects:[{projectId,income,hours,salary,commission,ratio}]}`。个人盈亏平衡用实际成本字段；累计不平均百分比。
- `validateTimes(state, rows, {replaceIds=[]}={})`：`{errors:[],warnings:[]}`；日常输入必须日期、成员身份、角色、正数0.5小时步进、日／月上限、工作日、明确时段无重叠、未锁定。批量内及已有记录一起判断，替换记录排除旧 id。返回适合直接展示的中文错误。
- `submitTimes(state, rows, expectedRevision=state.revision)`：覆盖 rows 中已有 id（仅本人记录），其余新增，置 submitted；复用 validateTimes，版本冲突／锁定拒绝。
- `saveDrafts(state, rows, expectedRevision=state.revision)`：保存草稿，不参与核算，锁定月禁止；保留不完整草稿以便补充。
- `deleteTime(state, id, expectedRevision=state.revision)`：删除未锁定记录并留痕。
- `updateSettings(state, projectId, month, {ratios:[{personId,ratio}],expenses:{accountManager,yearBonus}}, expectedRevision=state.revision)`：验证成员、比例合计及金额，覆盖当月比例及这两项预计费用，不影响其他科目，锁定月份拒绝。
- `previewImport(state, type, month, rows)`：类型 salary / commission / bonus / exception / fixed；rows 为 `{projectId?,personId?,value}`，value 为数字或空字符串／null，公式字符串拒绝。返回 `{id,type,month,revision,rows:[{key,projectId,personId,oldValue,newValue,kind,error}],errors:[]}`；kind 为 new / update / skip / error。同一类型按业务身份定位，工资奖金不展开项目；校验缺失、重复、权限范围（已登记人员／成员）、月份／锁定及金额非负。
- `applyImport(state, preview, expectedRevision=preview.revision)`：仅在无 errors 时一次性写入全部有效行，空白跳过，0 覆盖，不追加累计；批次 id 已应用则返回原状态以满足重试幂等。重新核验预览内容和当前状态，不信任被改动的 preview。返回新状态并写 batches。
- `correctAmount(state, collection, id, amount, reason, expectedRevision=state.revision)`：工资、提成、奖金、实际费用、预计费用中已有记录授权纠错，由 UI 允许财务；金额非负、原因必填、锁定及版本校验。
- `closeMonth(state, month, expectedRevision=state.revision)`：完整性检查无缺失后保存项目／人员输入依据及计算快照并锁定，重复月结拒绝。
- `reopenMonth(state, month, reason, expectedRevision=state.revision)`：原因必填；如存在更晚已结月份则拒绝并提示先反结账后续月；记录操作后移除锁定。结果使用 closed 快照，不静默覆盖。

来源数组条目：`{id,label,kind,month,amount,projectId?,personId?,detail}`。完整性缺失须覆盖工资、标准工时、有效收入比例；有收入项目的成员比例缺失时列明。0 金额与缺数据区分，草稿不计项目工时。

## 页面契约

页面脚本导出 `ProjectSchedule.render(ctx)`、`ProjectFinance.render(ctx)`、`ProjectAnalysis.render(ctx)`，返回 HTML 字符串；`ctx` 提供 `state, month, personId, role, page, filters, esc, money, percent`。行为交由 `app.js` 的事件委托调用模型，页面不复制计算公式。

`ui.js` 提供安全转义、金额格式化、表格、卡片及对话框的共用展示函数。模块控制器集中管理业务页签、过滤条件、弹窗、存储与身份切换；独立运行与工作台运行使用同一份业务代码。

## 月结完整性与规则快照补充

monthMissing(state, month) 返回截至该月适用项目/人员各月必要输入缺失，带月份与实体名；仅“无法测算”说明不阻断。财务工作台、试算与closeMonth共用此接口。后续已结月存在时，禁止更早月写入（含跨月替换原期间与目标期间）和月结，先从后往前反结账。closed[month].rules保存规则版本、税率、工时精度和个人盈亏平衡公式。

## Excel传输层

`ProjectExcel.createTemplate(state,month,id)` 异步返回 `{buffer,filename,manifest}`；一个文件覆盖五类，仅两个可见 Sheet：人员固定成本（salary/bonus）、项目核算数据（commission/exception/fixed）。身份及原值预填并锁定，黄色列可填，内部信息在人员页隐藏第4行，无第三张工作表。schema 为 ERP-I005-XLSX-v2。

`ProjectExcel.readTemplate(buffer,state,manifests)` 返回 `{month,revision,templateId,groups:[{type,rows}]}`，检查登记、全底账指纹和版本、结构、不可变列及非负数值。`previewWorkbook(state,result,sourceFile)` 返回含五类预览的整体预览、签名及来源；`applyWorkbook(state,preview)` 先检查全部异常和原版本，基于同一模型依次构造内存中的新状态，全部成功才返回，由 UI **持久化一次**。按涉及类型留批次，均附 sourceFile/templateId/excelWorkbookId；同一工作簿预览重试幂等。Excel层不计算业务金额。

ExcelJS4.4使用本地bundle。manifest存在独立本地存储 erp-project-demo-v1-excel-templates，刷新后可上传原模板。app.js 仅在用户文字请求后生成回复附件，文件消息校验后在同一对话展示差异，文字“确认导入”才执行写入；“取消”清除待确认。无生成、读取或导入按钮，无类型月份表单。异步操作绑定弹窗序号，关闭/切换后不继续写入。模拟聊天规则不等同真实小龙虾服务。
