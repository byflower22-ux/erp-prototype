# 龙虾 Excel 录入修订

日期：2026-11-09。迭代：ERP-I005。状态：历史实现与证据，当前交互已由[龙虾纯对话修订](龙虾纯对话修订.md)取代。

用户补充：龙虾信息录入不能直接在页面输出可填写表格，应输出包含模板的Excel，填写后再导入Excel。

## 上一版操作（历史）

顶部“模拟小龙虾” → 选择类型/月份 → **生成并下载 Excel 模板** → 用 Excel 填黄色“录入金额（元）”列并保存 → 对话中上传 .xlsx → **读取 Excel 并预校验** → 只读差异预览 → **确认本预览并写入**。输入数据始终在Excel中录入，页面只展示附件与上传控件；差异表为只读确认。

五类统一支持：月固定人工、项目人员提成、人员月度奖金、项目异常费用、项目固定成本分摊。模板预填序号、人员编号/名称、项目编号/名称、角色、月份及原金额，只解锁黄色金额列，带冻结表头、金额格式和非负数字验证。格式为真实OpenXML .xlsx，并非CSV改扩展名。ExcelJS4.4本地bundle及MIT许可证随代码归档，运行无需CDN。

空白跳过；0覆盖为0；公式/文本/日期/负数拒绝。全部预填列和表头、工作表结构、模板注册/版本/全底账指纹校验；生成后底账变化须重新生成模板，已结月及影响后续已结月的历史期间不可导入。文件最大5MB；出错保留上传入口。模板注册存于当前浏览器，刷新仍可导回；重置示例会清除注册。有效文件可以调整完整行顺序，不能增删记录或改身份。

确认写入继续复用同一模型的previewImport/applyImport，保持幂等、版本及月结规则，批次保留实际文件名和模板编号。ERP财务页只查询批次和结果，不新增业务文件上传页。龙虾对话编排仍为模拟，Excel生成/读取已实际执行，文件不发送外部服务。

完整浏览器实际下载 .xlsx，用ExcelJS写入填数后保存，再经页面文件选择器上传；断言预览前不产生批次、确认后相应金额更新。五类全部覆盖；工资仅补许映舟11000而其余空白，人员奖金输入0不生成项目分摊。

专项覆盖：非Excel/损坏文件、不同类型模板错配、模板跨刷新保留、预览后外部版本冲突、旧版文件拒绝、超5MB、模板注册保存失败时不输出不可导回文件。单元还覆盖日期/负值/公式缓存、身份/表头/增删行、排序、同版本底账变化、空白文件及锁定。
