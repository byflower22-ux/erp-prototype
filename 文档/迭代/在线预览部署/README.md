# GitHub 在线预览部署

日期：2026-10-27。部署范围为 ERP 统一工作台及已接入的预算优化（ERP-I003）、回单对接（ERP-I004）。

- Git 仓库：https://github.com/byflower22-ux/erp-prototype
- 在线入口：https://byflower22-ux.github.io/erp-prototype/
- 发布方式：GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保留原目录和静态资源，不依赖 Jekyll 或后端构建。

## 需求与发布流程

保留统一入口、公共导航、工作页签、版本标记及各模块原有业务交互。按现有相对路径整体发布 `index.html`、`原型/` 和 `文档/`，确保中文路径和资料链接可访问。排除本地 Word 渲染缓存、Python 缓存、依赖及环境配置。

流程：本地校验 → 提交到 Git → 推送 `main` → GitHub Pages 构建 → 检查线上资源与浏览器交互。此次仅发布既有原型，原型入口及需求资料继续在原迭代目录维护。

## 原型与操作手册

打开在线入口即可进入统一工作台。左侧“财务预算”“申请”“审批”“审批确认”切换业务页面，顶部页签可切换及关闭。版本标记与可视化配置继续使用现有工具栏。

原型展示示例数据，不连接真实付款、CBS 或金蝶接口。浏览器保存的数据及标记配置按站点隔离；本地 `file:` 环境中的配置不会自动迁入线上站点。可使用原有导入／导出功能转移版本标记配置。

后续更新：修改对应迭代源码和资料，运行相关检查后提交并推送 `main`，等待仓库 Pages 部署完成，再刷新预览。浏览器中的个性化标记配置需要导出并更新项目配置后才会共享给其他访问者。
