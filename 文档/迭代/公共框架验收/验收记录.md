## 复验

在 ERP 根目录执行：

```powershell
node --test 原型/公共/tests/workspace.test.cjs
node --test 原型/付款报销/回单对接/tests/*.test.js
# 使用已安装的 Playwright 与 Chrome；也可指定本机 Playwright 模块目录
$env:ERP_PLAYWRIGHT_MODULE = '本机的 Playwright 模块目录'
node 原型/公共/tests/browser-smoke.cjs
```

浏览器脚本默认通过本地文件打开根入口；可用 `ERP_ENTRY_URL` 指定 HTTP 地址。测试使用新浏览器上下文和示例数据，结果及截图写入本目录。
