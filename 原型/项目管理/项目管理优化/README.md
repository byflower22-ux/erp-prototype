# ERP-I005 项目管理优化 Demo

日期：2026-11-09。状态：用户批准设计，前端交互 Demo 已实现。

- [ERP 统一工作台](../../../index.html)：左侧“项目管理”“财务管理 → 核算工作台”“核算分析”进入。
- [独立原型](index.html)：手机浏览建议直接打开此入口。
- [操作手册](../../../文档/迭代/项目管理优化/操作手册.md)、[验收记录](../../../文档/迭代/项目管理优化/Demo验收记录.md)、[迭代资料](../../../文档/迭代/项目管理优化/README.md)。

Web 五页共用一个 project 模块 iframe、同一底账及计算模型。手机日程与 Web 共用保存数据和校验。虚构项目/人员、2026-09 至 2026-11 示例；11月工资刻意缺一条，供演示完整性与补齐后月结。工资、利润及派生人工均由 model.js 实际计算。

| 文件 | 负责内容 |
|---|---|
| model.js | 核算、工时、导入、版本、快照及锁定纯函数 |
| excel-io.js / vendor/ | 全部五类合并双Sheet的.xlsx生成/读取，ExcelJS4.4本地依赖及MIT许可 |
| app.js | 页面/页签、弹窗、保存、权限演示、模拟AI和导入编排 |
| schedule.js / finance.js / analysis.js | 日程、财务工作台和两分析看板 |
| ui.js / styles.css | 复用控件、系统色及响应式布局 |
| tests/ | 模型、视图和浏览器验收脚本 |

直接双击 index.html 可运行，无打包/安装依赖。开发检查使用 Node；浏览器验收使用已安装 Playwright，可通过 ERP_PLAYWRIGHT_MODULE 指定包路径，ERP_QA_OUTPUT 指定迭代证据目录。运行命令见验收记录。

龙虾是演示辅助对话，现已支持真实Excel模板下载、在Excel中填写及文件上传解析；文件仅在本地浏览器处理，不连接真实小龙虾。AI 只用预设候选，不识别材料。生产鉴权、同步接口、历史数据迁移、问数服务 L06 均需后续联调。

公共接入复用 ERPClient.connect({snapshot,navigate,activate,close}) 和 erp-workspace-v1 协议；一个常驻 iframe 保留查询及编辑状态。统一版本标记保留预算13项，追加本迭代5项；已有浏览器个人配置继续保留，需要时在配置面板“恢复项目配置”后查看新增默认项。

临时输出放本迭代 .cache/，正式证据放 文档/迭代/项目管理优化/验收证据/。

龙虾采用纯对话：输入录入请求后直接回复双Sheet Excel附件，选择填写后的文件发送，再回复“确认导入”。详见[当前变更与验证](../../../文档/迭代/项目管理优化/龙虾纯对话修订.md)。
