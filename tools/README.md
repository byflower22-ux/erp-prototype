# ERP 维护工具

本目录仅维护可重复使用的生成工具，不存放生成结果或一次性中间文件。

| 工具 | 用途 | 正式输出 |
|---|---|---|
| `build_budget_requirements_docx.py` | 根据预算优化主需求生成 Word，调用状态流转图生成工具 | `文档/迭代/预算优化/预算优化详细需求说明_V1.11.docx` |
| `draw_budget_state_flow.py` | 生成预算状态流转图 | `文档/迭代/预算优化/图片/` |

Word 转 PDF、逐页渲染、提取文本及版式检查时，应显式指定 `文档/迭代/预算优化/.cache/文档检查/<文档版本>/` 作为输出目录。其他迭代使用自己的 `.cache/`。这些中间文件仅本地保留，已通过 `.gitignore` 排除；对外交付的图片和验收记录应从中挑选后放入正式图片或验收目录。

一次性修订脚本、原稿检查副本、临时导出配置也放迭代 `.cache/` 对应子目录；有长期维护价值的脚本经整理后再纳入本目录。
