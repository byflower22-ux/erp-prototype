# ERP 项目

本目录用于维护 ERP 统一原型、公共交互规范和各次迭代资料。

在线预览：[ERP 统一工作台](https://byflower22-ux.github.io/erp-prototype/)；Git 仓库：[erp-prototype](https://github.com/byflower22-ux/erp-prototype)。发布方式与操作说明见[在线预览部署](文档/迭代/在线预览部署/README.md)。

**日常使用入口：[ERP 统一工作台](index.html)**，直接打开即可。预算优化与回单对接共用左侧菜单、顶部栏和工作页签；切换业务模块保留本次页面中的查询及编辑状态。

- `原型/`：按业务模块维护可运行原型和公共组件。
- `文档/迭代/`：按迭代保存需求、流程图、测试用例、操作手册等产出。
- 当前已纳入：预算优化（ERP-I003）、回单对接（ERP-I004）。

## 维护约定

公共[版本标记组件](原型/公共/版本标记.md)统一管理页面与菜单：顶部只有一条“版本标记”工具栏，点击“显示标记”同时查看变化。当前默认采用用户确认导出的 13 项（页面 10 项、菜单 3 项），顺序及内容见[默认配置发布说明](文档/迭代/预算优化/版本标记项目默认配置.md)。后续迭代继续复用，接入与验证见[预算记录](文档/迭代/预算优化/版本标记接入.md)。

可视化入口：工作台顶部“版本标记 → **配置标记**”，选择范围“页面区域／菜单区域”，在同一面板新增、编辑、点选及管理迭代。保存到当前浏览器；导出 JSON 统一包含两类配置，导出脚本可更新公共 `version-marks-config.js`。旧页面与菜单本地配置首次自动合并。详见[配置说明](原型/公共/版本标记.md#可视化配置入口)。

编号贴近原区域，仅在遮字或相撞时向附近空白处稍作偏移，页面及侧栏宽度保持原样。预算嵌入工作台时隐藏重复工具栏，独立打开时保留本地入口。

- 原型按业务模块放入 `原型/<业务模块>/<迭代名称>/`，迭代资料放入 `文档/迭代/<迭代名称>/`。
- 每个迭代的 README 索引需求、流程、原型、测试、操作手册和归档记录；迭代状态统一登记到[迭代台账](文档/迭代台账.md)。
- 2026-10-23 先纳入既有版本，再完成公共框架第一阶段接入；源项目保留，ERP 内副本通过适配层接入公共菜单和工作页签。
- 归档清单记录来源、目标相对路径及 SHA-256；仅用于核对迁入基线，后续改动在对应迭代维护变更记录。
